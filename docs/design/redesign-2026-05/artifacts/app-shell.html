App shell

A two-pane frame on the tier 0 floor: a fixed sidebar (separated by a right border) and a content column whose topbar carries breadcrumbs and a per-page action cluster. The nav set is Inbox · Issues · Agents · Settings plus saved views — deliberately no Tasks or Runs; those live inline on the issue.
